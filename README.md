# Neely Labs organization defaults

This special repository supplies the public profile, shared community-health
files, workflow templates, repository protection policies, and bootstrap/audit
utilities for the [Neely Labs](https://github.com/neely-labs) organization.

Neely Labs is the open-source and experimental software studio of Neely
Solutions LLC. See [the organization policy](docs/ORGANIZATION_POLICY.md) for
the ownership, client-work boundary, access, publication, and stewardship
rules.

## Contents

- [`profile/README.md`](profile/README.md) — organization profile.
- [`docs/PUBLISHING_CHECKLIST.md`](docs/PUBLISHING_CHECKLIST.md) — publication gate.
- [`rulesets/`](rulesets) — canonical experiment and maintained protections.
- [`scripts/bootstrap-repo`](scripts/bootstrap-repo) — private-by-default creation.
- [`scripts/apply-ruleset`](scripts/apply-ruleset) — guarded protection setup.
- [`scripts/audit-org`](scripts/audit-org) — read-only drift detection.
