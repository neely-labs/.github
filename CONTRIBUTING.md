# Contributing

Thanks for helping improve a Neely Labs project.

Before starting substantial work, open an issue or discussion in the relevant
repository so scope and direction can be aligned. Small corrections may go
directly to a pull request.

## Pull requests

1. Keep the change focused and explain the problem it solves.
2. Add or update tests for behavior changes.
3. Run the repository's documented verification commands.
4. Update documentation when behavior or public interfaces change.
5. Resolve review conversations before merge.

Contributions are provided under the same license that covers the repository.
Do not include code, data, credentials, or other material that you do not have
the right to contribute.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
