# Neely Labs

Neely Labs is the open-source and experimental software studio of
[Neely Solutions LLC](https://neelysolutions.com), operated separately from its
client services practice.

This is where [Nick Neely](https://github.com/nick-neely) builds and maintains:

- open-source tools and libraries;
- experiments and technical prototypes; and
- independent side projects.

Projects begin privately and are published intentionally. Public repositories
identify their maturity, license, maintenance status, and security reporting
path. Client code, client data, contractual work product, and client secrets do
not belong here without an explicit rights and confidentiality review.

## Project maturity

- `experiment` — exploratory work with no stability promise.
- `maintained` — actively supported work with documented verification and
  protected changes.
- `archived` — preserved for reference and no longer actively maintained.

Security concerns should be reported privately through the repository's
**Security** tab, not through a public issue.
